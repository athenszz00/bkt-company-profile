# BKT Company Profile

Website company profile CV. Bhatara Kresna Tunggal berbasis React + Vite (JavaScript), tanpa login, responsive untuk desktop/tablet/mobile, dan siap deploy ke Vercel.

## Menjalankan lokal
```bash
npm install
npm run dev
```

## Build production
```bash
npm run build
```

## Deploy Vercel
1. Upload project ke GitHub.
2. Import repository di Vercel.
3. Framework preset: Vite.
4. Build command: `npm run build`.
5. Output directory: `dist`.
